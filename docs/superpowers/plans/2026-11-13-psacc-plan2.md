# PSACC Plan 2 — Locais, Cargas, Viagens, Consumo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the charge automation location-aware (act only at Casa, one "charge" at Trabalho) and fill the Cargas, Viagens and Consumo screens plus new Painel cards.

**Architecture:** Extend the lenient REST models/`CarSnapshot` with odometer, position time and battery health; add places + a pure `locate()`; feed snapshots to pure charge/trip detectors that persist sessions; new API routes; four frontend pages/sections reuse the Plan 1 visual language.

**Tech Stack:** existing (FastAPI, SQLModel, pydantic v2, React/TS, Tailwind, react-query, recharts) + `leaflet` / `react-leaflet` (OSM tiles).

**Spec:** `docs/superpowers/specs/2026-11-13-psacc-plan2-design.md` (and Plan 1 spec/CLAUDE.md for global rules).

## Global Constraints

- All Plan 1 constraints hold (pt-PT UI, 24 h, DD/MM/AAAA, EUR, `Atlantic/Azores`, UTC storage, `/data`, `X-PSACC` header on non-GET, lenient models, `None` = unknown).
- REST is the only source of `plugged`/`charging`/position/odometer; MQTT only soc/autonomy.
- No new car wake-ups: detectors use only the snapshots the poller already gets.
- Automation acts only at Casa; at Trabalho it sends "charge" **once per plug-in episode** (respects the automation switch, ignores battery limit); never "defer" outside Casa.
- Place radius default **150 m**; position stale after **60 min** only if the odometer advanced since the position fix.
- Usable battery capacity default **46 kWh** (`AppConfig.battery_capacity_kwh`, editable).
- Work charges cost **0 €**; home = EDA tariff per period; other place = its €/kWh or unset (editable).
- Labels: "Vida útil da bateria" (never "SoH"), "Cabo", "Quilometragem".
- History kept forever (no retention job).

## Review Focus

1. **Car parked at home overnight, position timestamp hours old, odometer unchanged** → still "Casa", automation acts → `test_locate_old_fix_same_mileage_is_home` (Task 2).
2. **Car arrives at work still in deferred mode** → exactly one "charge" command per plug-in episode, none on later polls → `test_work_charge_once_per_episode` (Task 3).
3. **No Casa configured after upgrade** → no commands, reason "Defina o local Casa" → `test_decide_no_home_place` (Task 3).
4. **App starts mid-charge** → session created with `partial=True`, soc_start = first observed → `test_session_started_mid_charge_is_partial` (Task 5).
5. **Charge spanning vazio→cheias at home** → cost split by period with the price valid that day → `test_home_cost_split_by_period` (Task 5).

### Task 2: Places + locate()

**Files:** Create `backend/psacc/places.py`; Modify `backend/psacc/store.py`; Create `backend/psacc/api/places.py`, register in `main.py`; Tests `backend/tests/test_places.py`, `test_api.py`.

**Interfaces — Produces:**
- `Place(BaseModel)`: `id: int | None`, `name: str`, `kind: Literal["home","work","other"]`, `lat: float`, `lon: float`, `radius_m: int = 150` (25–2000), `price_eur_kwh: float | None` (only for `other`, ≥0).
- `store.list_places() -> list[Place]`, `store.save_place(p) -> Place` (enforce ≤1 home, ≤1 work → `ValueError` pt-PT), `store.delete_place(id)`.
- `PositionFix(BaseModel)`: `lat, lon, at: datetime, mileage_km: float | None`; `store.get_position_fix()/set_position_fix()`.
- `Where = Literal["home","work","other","unknown","unset"]` (`unset` = no home place configured).
- `distance_m(lat1, lon1, lat2, lon2) -> float` (haversine).
- `place_at(lat, lon, places) -> Place | None` (nearest containing).
- `update_fix(car: CarSnapshot, fix: PositionFix | None) -> PositionFix | None` — new fix when car has lat/lon and `position_at` newer than the stored fix.
- `locate(now, car, fix, places) -> tuple[Where, Place | None]`: `unset` if no home; `unknown` if no fix, or fix older than 60 min **and** `car.mileage_km` is known and differs from `fix.mileage_km` by > 0.1 km; else place kind or `other` (outside all places, place None).
- API: `GET /api/places`, `POST /api/places`, `PUT /api/places/{id}`, `DELETE /api/places/{id}`, `POST /api/places/from-car {name, kind}` (uses current fix; 409 pt-PT "Posição do carro desconhecida" if none). 422 pt-PT on validation.

- [ ] **Step 1: Tests** — haversine sanity (~1.11 km per 0.01° lat); `test_place_at_nearest_inside_radius`; `test_locate_unset_without_home`; `test_locate_old_fix_same_mileage_is_home`; `test_locate_old_fix_moved_is_unknown`; `test_save_second_home_rejected`; API CRUD + from-car 409.

- [ ] **Step 5: Commit** `feat: places and location of the car`

### Task 3: Location-aware automation + work charge

**Files:** Modify `backend/psacc/automation/decide.py`, `backend/psacc/automation/engine.py`, `backend/psacc/store.py`; Tests `backend/tests/test_decide.py`, `test_engine.py`.

**Interfaces — Consumes:** Task 2 `locate`, `update_fix`, `store` place/fix fns. **Produces:** `decide(now, cfg, tariff, car, override, where: Where = "home", work_charge_sent: bool = False) -> Decision` (defaults keep Plan 1 tests valid).

Rules inserted after the existing "automation off / unknown state / unplugged" checks and before override/limit/tariff:
- `where == "unset"` → `None`, "Defina o local Casa".
- `where == "unknown"` → `None`, "Posição do carro desconhecida".
- `where == "work"` → `Decision("charge", "Carga no Trabalho")` if not `work_charge_sent` else `None`, "No Trabalho (carga já pedida)". Override is ignored here (car charges anyway).
- `where == "other"` → `None`, "Fora de Casa" (override still honoured: manual charge → "charge").
- `home` → existing Plan 1 rules unchanged.
Engine: on each status, `fix = update_fix(...)` (persist), compute `where`; keep `work_charge_sent` in a StateRow (`work_episode`) — set True after a work "charge" round starts; cleared when car unplugged or `where != "work"`. Work rounds reuse verify/retry; failure alert text: "⚠️ PSACC: não consegui iniciar a carga no Trabalho." Activity log "Carga no Trabalho iniciada".
- [ ] **Step 1: Tests** — `test_decide_no_home_place`, `test_decide_unknown_position`, `test_decide_work_charge_once`, `test_decide_other_place_no_command`, `test_decide_other_place_manual_override_charges`; engine: `test_work_charge_once_per_episode` (two work snapshots → 1 command; unplug → replug → new command), `test_no_defer_outside_home`, `test_home_rules_unchanged` (existing engine tests still pass).
- [ ] **Steps 2–4:** FAIL → implement → PASS (full suite).

### Task 5: Charge sessions + cost

**Files:** Create `backend/psacc/history/__init__.py`, `history/charges.py`, `history/cost.py`; Modify `store.py`, `engine.py` (feed detector from `on_status`); Tests `backend/tests/test_charges.py`, `test_cost.py`.

**Produces:**
- `ChargeSession(BaseModel)`: `id, started_at, ended_at|None, place_kind: Where, place_name|None, soc_start, soc_end|None, kwh|None, cost_eur|None, price_override_eur_kwh|None, partial: bool`; samples `ChargeSample(session_id, at, soc, rate_kmh)`.
- `ChargeDetector.feed(snap, where, place) -> list[Event]` pure state machine: start when `charging is True` (or soc rises ≥1 % while plugged), end when `charging is False` for 2 consecutive fresh snapshots, or unplugged; first snapshot already charging → `partial=True`. Ignores snapshots whose `energy_at` didn't advance.
- `session_kwh(soc_start, soc_end, capacity) = max(0, soc_end-soc_start)/100*capacity`.
- `session_cost(session, samples, tariff, capacity) -> float | None`: home → split kWh across samples by `period_at` at each interval midpoint × `tariff.price_at(period, day)`; work → 0.0; other with place price → kWh × price; override price wins; unknown → None.
- `store.charge_sessions(limit, offset)`, `store.charge_samples(id)`, `store.set_session_price(id, eur_kwh)`.
- [ ] Tests: `test_session_start_end`, `test_session_started_mid_charge_is_partial`, `test_unplug_ends_session`, `test_stale_energy_ignored`, `test_home_cost_split_by_period` (00:10–07:30 winter weekday: vazio until 07:00 then cheias, prices 0.10/0.20 → exact €), `test_work_cost_zero`, `test_other_no_price_is_none`, `test_price_override`.
